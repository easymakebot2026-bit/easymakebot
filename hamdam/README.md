# همدم (Hamdam)

همدم ربات مراقبت روزانه از والدین سالمند است، برای خانواده‌هایی که در کشورهای مختلف زندگی می‌کنند. با بله داخل ایران و تلگرام خارج از ایران کار می‌کند و طوری ساخته شده که در قطعی اینترنت هم مراقبت ادامه پیدا کند.

جزئیات طراحی: [`docs/DESIGN.md`](docs/DESIGN.md) · متن معرفی در لینکدین: [`docs/LINKEDIN.md`](docs/LINKEDIN.md)

## ساختار

| فایل | کار |
|---|---|
| `main.py` | نقطه‌ی شروع: بات‌ها، زمان‌بند، صف پیام و وب‌سرور |
| `config.py` | تنظیمات هر گره از `.env` |
| `node.py` | شیء گره: دیتابیس، کانال‌ها، فراخوانی گره‌ی دیگر (`call`/`command`/`deliver`) |
| `peer.py` | ارتباط امضاشده بین گره‌ها، صف پیام (Outbox)، ضربان و تشخیص قطعی |
| `services.py` | عملیات حلقه‌ی مراقبت (RPC) و رفتار در برابر پیام‌های والدین |
| `scheduler.py` | چرخه‌ی دقیقه‌ای: احوال‌پرسی، دارو، یادآوری، هشدار، گزارش شبانه |
| `billing.py` | زرین‌پال (تومان) و TON (دلاری، با تأیید ادمین) |
| `handlers.py` | گفت‌وگوی ربات: منوی خانواده، والدین، ادمین |
| `logic.py` | منطق خالص و تست‌شده: زمان‌ها، تشخیص پیام نگران‌کننده، کدها |
| `texts.py` | همه‌ی متن‌ها به فارسی و انگلیسی |
| `web.py` | مسیرهای `/peer`، `/pay/zarinpal/callback` و `/health` |

## اجرای محلی (یک گره، فقط تلگرام)

```bash
python3 -m venv venv && source venv/bin/activate
pip install -r hamdam/requirements-dev.txt
cp hamdam/.env.example .env
# در .env این‌ها را تنظیم کنید:
#   NODE_ID=global
#   TELEGRAM_BOT_TOKEN=...
#   ELDER_CHANNEL=telegram
#   ADMIN_CHANNEL=telegram
#   PEERS=   (خالی)
#   DATABASE_URL=sqlite+aiosqlite:///hamdam.db
python -m hamdam.main
```

برای تست، با یک حساب تلگرام نقش فرزند را بازی کنید و یک «پدر/مادر» اضافه کنید. بعد با حساب دوم کد ۸ رقمی را برای ربات بفرستید تا نقش والدین را داشته باشد.

## تست‌ها

```bash
pip install -r hamdam/requirements-dev.txt
python -m pytest hamdam/tests -q
```

`test_two_nodes.py` دو گره‌ی واقعی (ایران و خارج) را داخل یک پروسه اجرا می‌کند و این سناریوها را شبیه‌سازی می‌کند:
- ثبت‌نام و اتصال مادر
- پیام نگران‌کننده
- داروی تأییدنشده
- قطعی اینترنت (پیامک به رابط محلی و یک پیام آرام به خارج)
- وصل شدن دوباره و تحویل پیام‌های صف
- پرداخت TON و تمدید اشتراک روی گره‌ی ایران

## استقرار دو گره

1. **سرور ایران:** `NODE_ID=ir`، توکن بات بله، `ELDER_CHANNEL=bale`، کاوه‌نگار، زرین‌پال، `DEFAULT_TZ=Asia/Tehran`
2. **سرور خارج:** `NODE_ID=global`، توکن تلگرام، `ELDER_CHANNEL=telegram`، کیف پول TON
3. روی هر دو سرور، `PEERS` به آدرس گره‌ی دیگر اشاره کند و مقدار `PEER_KEY` یکسان باشد.
4. ساخت image:

   ```bash
   docker build -f hamdam/Dockerfile -t hamdam .
   ```

   هر گره Postgres خودش را دارد. پورت `8090` باید پشت HTTPS باشد، مثلاً با Caddy، همان روشی که در `deploy/` استفاده شده.

> **وضعیت پشتیبانی از بله:** بله از نظر API با تلگرام سازگار است و همدم با همان کتابخانه‌ی aiogram به آن وصل می‌شود. ولی پیش از عرضه باید روی بات واقعی بله تست شود: دکمه‌ها، پیام صوتی و لینک `ble.ir`. بخش ۹ سند طراحی را ببینید.
